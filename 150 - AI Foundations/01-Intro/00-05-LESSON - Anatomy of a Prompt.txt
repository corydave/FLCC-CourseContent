      <span class="beat__label"><svg class="i"><use href="#i-layers"/></svg> Beat 5 &middot; Content</span>
      <div class="segment">
        <h3><span class="segno">01</span> The five components</h3>
        <div class="prose">
          <p>A working prompt does five jobs. <strong>Task</strong>: what you actually want done, stated as a verb. <strong>Audience</strong>: who is going to read it. <strong>Format</strong>: what shape the output should take, including how long. <strong>Constraints</strong>: what to leave out, avoid, or never say. <strong>Examples</strong>: a sample of the thing you want, which is worth more than any adjective describing it.</p>
          <p>Most people write only the first one, and only vaguely. The panel below starts from the worst possible version and adds one component at a time. Watch the output, not the meter.</p>
        </div>

    <section class="block beat">
      <span class="beat__label"><svg class="i"><use href="#i-layers"/></svg> Beat 6 &middot; Content</span>
      <div class="segment">
        <h3><span class="segno">02</span> The one that does nothing</h3>
        <div class="prose">
          <p>You will have noticed the politeness button. Adding <em>please</em> and <em>thank you</em> does not change the output in any way you could measure, and it does not move the specificity meter, because it adds no information about what you want.</p>
          <p>The same is true of a whole family of instructions people reach for: <em>be accurate</em>, <em>be creative</em>, <em>do a good job</em>, <em>this is important</em>. They feel like they are steering something. They are not, because there is no accuracy dial for them to turn - which is Lesson 8's whole subject.</p>
          <p>Be polite to it if you like. Plenty of people do, and it costs you a couple of tokens. Just do not mistake it for prompt engineering.</p>
        </div>
        
        <div class="callout">
          <div class="icontile"><svg class="i"><use href="#i-lightbulb"/></svg></div>
          <div class="callout__body">
            <p class="callout__label">The highest-leverage component</p>
            <p>If you only ever add one thing, add <strong>an example</strong>. A paragraph you like, a table laid out the way you want it, an email in the right register. Describing a tone takes four sentences and lands unreliably; showing one takes ten seconds and lands almost every time.</p>
          </div>
        </div>
      </div>
    </section>

/* Two-click YouTube facade.
 *
 * A .embed--facade renders as our own markup - no iframe, no request to Google.
 * The iframe is built on click, with autoplay, because by then the learner has
 * asked for it. One delegated listener handles every facade on the page, and
 * including this file twice is harmless.
 *
 * Markup it expects:
 *   <div class="embed embed--facade"
 *        data-video="VIDEO_ID"
 *        data-title="What the video is"
 *        data-sub="Demo · 2:40"            (optional)
 *        data-poster="../media/posters/ID.jpg"   (optional, self-hosted)
 *        data-start="95">                  (optional, seconds)
 *   </div>
 */
(function () {
  "use strict";
  if (window.__facadeReady) return;
  window.__facadeReady = true;

  var PLAY = '<svg viewBox="0 0 24 24" class="i" aria-hidden="true"><polygon points="6 3 20 12 6 21 6 3"/></svg>';

  function build(el) {
    if (el.querySelector(".facade")) return;
    var poster = el.getAttribute("data-poster");
    var title  = el.getAttribute("data-title") || "Play video";
    var sub    = el.getAttribute("data-sub") || "";
    var b = document.createElement("button");
    b.type = "button";
    b.className = "facade" + (poster ? "" : " facade--noposter");
    b.setAttribute("aria-label", "Play: " + title + ". The video loads from YouTube only after this.");
    b.innerHTML =
      (poster ? '<img class="facade__poster" src="' + poster + '" alt="" loading="lazy">' : "") +
      '<span class="facade__scrim"></span>' +
      '<span class="facade__play">' + PLAY + "</span>" +
      '<span class="facade__meta"><span class="facade__title"></span>' +
      (sub ? '<span class="facade__sub"></span>' : "") + "</span>";
    b.querySelector(".facade__title").textContent = title;
    if (sub) b.querySelector(".facade__sub").textContent = sub;
    // A poster that fails to load should degrade to the designed placeholder
    // rather than leaving a broken image over the play button.
    var img = b.querySelector(".facade__poster");
    if (img) img.addEventListener("error", function () {
      img.remove(); b.classList.add("facade--noposter");
    });
    el.appendChild(b);
  }

  function play(el) {
    var id = el.getAttribute("data-video");
    if (!id) return;
    var start = el.getAttribute("data-start");
    var src = "https://www.youtube-nocookie.com/embed/" + encodeURIComponent(id) +
              "?autoplay=1&rel=0&modestbranding=1" + (start ? "&start=" + encodeURIComponent(start) : "");

  }

  });

<script>
/* Talks to a host page when this lesson is embedded in one.

   The point is to kill the double scrollbar: the page reports how tall it
   actually is, the host resizes the iframe to match, and the inner scrollbar
   never appears. Everything scrolls once, in the outer page, the way a reader
   expects.

   Loaded on every page. When the page is not in a frame, the whole thing is a
   no-op - there is nobody to talk to. */
/* ---- LMS mode -------------------------------------------------------------
   Two ways in, on purpose:

     ?lmsembed=true   forced. Lets Dave open any page and see exactly what a
                      student in Brightspace sees, without an LMS.
     the handshake    automatic. The host says it is an LMS, so nothing has to
                      be added to a URL and there is nothing to mistype.

   What it hides is a list of ids, below. Anything carrying data-lms-hide is
   hidden too, so a new element can opt in where it is authored rather than by
   editing this file. */
(function () {
  "use strict";

  /* Elements that make sense on a standalone page and get in the way inside an
     LMS. Add ids here, or put data-lms-hide on the element itself.

     lessonNext - the "next lesson" link. In Brightspace the learner should use
     the LMS's own navigation: it records progress, and it does not leave them
     staring at blank space when the next lesson is shorter than this one and
     the frame has not shrunk yet. */
  /* scaffoldBtn is the Template view toggle: an authoring aid, meaningless to a
     student, and doubly wrong in a frame - it is position:fixed, which inside an
     iframe sized to its full content anchors it to the bottom of the whole
     document rather than the visible area, so it floats in the middle of the
     page. Hidden in the LMS, kept when a page is opened directly. */
  var LMS_HIDE = ["lessonNext", "scaffoldBtn"];

  function applyLmsMode() {
    var r = document.documentElement;
    if (r.getAttribute("data-lms") === "1") return;
    r.setAttribute("data-lms", "1");
    LMS_HIDE.forEach(function (id) {
      var el = document.getElementById(id);
      if (el) el.setAttribute("data-lms-hide", "");
    });
  }
  window.applyLmsMode = applyLmsMode;

  if (/[?&]lmsembed=true\b/i.test(location.search)) {
    if (document.readyState === "loading") {
      document.addEventListener("DOMContentLoaded", applyLmsMode);
    } else { applyLmsMode(); }
  }

  if (window.parent === window) return;          /* not embedded; nothing more */

  var TAG = "csc150";
  var last = 0;
  var host = null;                 /* what the embedding page told us about itself */

  /* Measure the content wrapper, not the document.

     Both documentElement and body stretch to fill the iframe's viewport, so
     once the host has made the frame tall neither of them can report a smaller
     number - the frame ratchets upward and never comes back down. Measured on
     the vocabulary page: filter 67 terms to 1 and the content is 679px while
     html and body both still report 13,469. scrollHeight has this problem and
     so does getBoundingClientRect; it is not a difference between them.

     The wrapper is content-sized, so it tells the truth in both directions. */
  function contentEl() {
    return document.querySelector(".lesson") ||
           document.querySelector("main.wrap") ||
           document.body;
  }

  function height() {
    var el = contentEl();
    var h = Math.ceil(el.getBoundingClientRect().height);
    /* Margins on the wrapper's children can escape its box; add whatever sits
       below it so the last line is never clipped. */
    var cs = window.getComputedStyle(el);
    return h + parseFloat(cs.marginTop || 0) + parseFloat(cs.marginBottom || 0) + 8;
  }

  function send() {
    var h = height();
    if (Math.abs(h - last) < 2) return;          /* sub-pixel churn is not news */
    last = h;
    /* Target the host's origin once the handshake has told us what it is.
       Before that it is unknown, so "*" is the only option - and height is not
       sensitive, which is why sending it before the handshake is acceptable. */
    window.parent.postMessage({ tag: TAG, type: "height", height: h },
                              (host && host.origin) || "*");
  }

  /* ---- handshake ---------------------------------------------------------
     The page announces itself; a host that understands the protocol answers
     with what it knows about the surrounding context. Everything in that reply
     is untrusted - it arrives from a window we did not write - so it is used
     only for cosmetics and for ids that are sanitised before use. */
  window.addEventListener("message", function (e) {
    if (e.source !== window.parent) return;
    var d = e.data;
    if (!d || d.tag !== TAG || d.type !== "host") return;
    host = {
      name: String(d.host || "").slice(0, 32).replace(/[^a-z0-9-]/gi, ""),
      course: String(d.course || "").slice(0, 32).replace(/[^0-9]/g, ""),
      topic: String(d.topic || "").slice(0, 32).replace(/[^0-9]/g, ""),
      chrome: !!d.chrome,
      origin: e.origin && e.origin !== "null" ? e.origin : null
    };
    var r = document.documentElement;
    r.setAttribute("data-embedded", host.name || "1");
    /* The host already shows a title above this frame, so showing ours too
       gives the learner the same heading twice. */
    if (host.chrome) r.setAttribute("data-host-chrome", "1");
    if (host.course) r.setAttribute("data-course-id", host.course);
    applyLmsMode();
    if (d.hash && /^[a-z0-9#_-]{0,64}$/i.test(d.hash)) {
      var el = document.getElementById(String(d.hash).replace(/^#/, ""));
      if (el) el.scrollIntoView({ block: "start" });
    }
    send();
  });

  /* Announce, then a few more times, then stop. The host's listener may be a
     separate file that has not finished loading when this runs, and a single
     announcement that arrives before anyone is listening is simply lost. The
     host also greets on first contact, so this is the belt to that braces. */
  (function announce(n) {
    if (host) return;                       /* greeted; nothing more to say */
    window.parent.postMessage({ tag: TAG, type: "ready" }, "*");
    if (n > 0) setTimeout(function () { announce(n - 1); }, 250);
  })(8);

  /* The interactives change height constantly - the gate unlocks, a deck card
     leaves, a candidate list redraws - so polling on load is not enough. */
  if (window.ResizeObserver) {
    /* Observing documentElement is useless for the same reason measuring it is:
       it does not change when the content shrinks inside a tall frame. */
    new ResizeObserver(send).observe(contentEl());
  } else {
    setInterval(send, 400);
  }
  window.addEventListener("load", send);
  window.addEventListener("resize", send);
  document.addEventListener("DOMContentLoaded", send);

  /* A full-height iframe has nothing to scroll, so scrollIntoView inside it
     does nothing - the element the page wanted to show is still off-screen,
     because the *frame* is off-screen. Redirect those calls to the host, which
     is the only window that can actually move.

     Patching a DOM prototype is worth a wince. It is done here rather than at
     the call sites because the call sites are spread across generated pages and
     will keep being added, and because this is precisely the boundary where
     the meaning of "scroll" changes. It is scoped to the embedded case only. */
  /* Only forward a scroll once the learner has actually done something. A page
     that moves the host window while it is still loading takes the reader
     somewhere they did not ask to go - and the LMS header and the lesson's own
     title scroll out of view, which looks like the top of the page vanishing.
     Anything a page does to itself on load stays inside the frame. */
  var touched = false;
  ["pointerdown", "keydown", "click"].forEach(function (ev) {
    document.addEventListener(ev, function () { touched = true; }, true);
  });

  var native = Element.prototype.scrollIntoView;
  Element.prototype.scrollIntoView = function (arg) {
    if (!touched) return native.apply(this, arguments);
    try {
      var r = this.getBoundingClientRect();
      var top = r.top + (window.scrollY || 0);
      var block = (arg && typeof arg === "object" && arg.block) || "start";
      /* Already in view: leave the host alone. Scrolling to something the
         reader can see is pure disruption. */
      if (r.top >= 0 && r.bottom <= (window.innerHeight || 0)) return;
      window.parent.postMessage({
        tag: TAG, type: "scroll", top: top, height: r.height, block: block,
        smooth: !(arg && arg.behavior === "auto")
      }, "*");
    } catch (e) {
      native.apply(this, arguments);
    }
  };
})();

<script>
/* Steady: stop interactives changing height under the learner's cursor.

   Every demo in this course has the same shape - content that swaps, and
   controls underneath it. When the content changes height the controls move,
   and a learner who is clicking the same button repeatedly ends up chasing it
   down the page. Token Roulette had this, Prompt Surgery had it, and every
   future interactive would have got it too.

   Two ways to hold a container still, and the difference matters:

     prime(el, n, render)  the states are enumerable, so render all of them
                           once before the learner sees anything, take the
                           tallest, and reserve it. No jump, ever.

     hold(el)              the states are combinatorial, so the best available
                           is a latch: never shrink below the tallest seen. It
                           can still grow once per new maximum.

   Prefer prime. hold is the fallback, not the default.

   Both re-measure on resize and once the real typeface has loaded, because a
   height measured in the fallback font is wrong by about a line. */
(function () {
  "use strict";
  var primed = [];
  /* measureAll re-renders the element to size each state, which is itself a
     layout change that a ResizeObserver will report. Without this flag the
     observer re-enters measureAll forever and the page hangs. */
  var measuring = false;

  function natural(el) {
    var prev = el.style.minHeight;
    el.style.minHeight = "";
    var h = el.getBoundingClientRect().height;
    el.style.minHeight = prev;
    return h;
  }

  function measureAll(el, n, render) {
    measuring = true;
    var prev = el.style.minHeight;
    el.style.minHeight = "";
    var max = 0;
    for (var i = 0; i < n; i++) {
      render(i);
      var h = el.getBoundingClientRect().height;
      if (h > max) max = h;
    }
    el.style.minHeight = prev;
    measuring = false;
    return max;
  }

  var Steady = {
    /* render(i) paints state i into el. measureAll leaves el in the LAST state
       it rendered, so somebody has to put it back.

       Passing restore() is strongly preferred over doing it after the call.
       Measuring happens more than once - on font load, on resize, and when a
       demo's prediction gate finally opens and gives it a real width - and only
       the first of those is followed by the caller's own code. Without restore,
       every later re-measure silently leaves the panel in its last state. That
       shipped as: Class Arena opening on its empty end-of-round summary, with
       the button that starts round one hidden.

       Two hooks, not one, because measuring MUTATES the panel's own state:
       render(i) drives the same variables the learner's clicks drive. So

         save()        -> an opaque snapshot of where the learner is, taken
                          immediately before a measurement pass
         restore(snap) -> put that back, and repaint

       Passing only restore is not enough: it would repaint from variables the
       measurement pass has already trampled. That is how Class Arena came to
       open on round three - the picker was visible, but ix had been left at 2
       by the last state measured. */
    prime: function (el, n, render, save, restore) {
      if (!el || !n) return 0;
      var rec = null;
      for (var i = 0; i < primed.length; i++) if (primed[i].el === el) rec = primed[i];
      if (!rec) { rec = { el: el, n: n, render: render, w: 0 }; primed.push(rec); }
      rec.n = n; rec.render = render; rec.save = save; rec.restore = restore;

      /* A demo inside an unopened prediction gate is display:none, so every
         state measures zero. Reserving 0px would be harmless but misleading;
         leave it unset and let the width observer take a real measurement the
         moment the gate opens. */
      var snap = save ? save() : null;
      var max = measureAll(el, n, render);
      if (max > 0) el.style.minHeight = max + "px";
      if (restore) restore(snap);
      rec.w = el.getBoundingClientRect().width;

      /* A height measured at the wrong width is the wrong height, and these
         demos are routinely measured at the wrong width: they sit inside the
         prediction gate at load, which is narrower and sometimes display:none,
         and the page may later be embedded in a resizing frame. Watch the
         element's own width and re-measure when it actually changes. Height
         changes are ignored, so re-measuring cannot feed itself. */
      if (window.ResizeObserver && !rec.ro) {
        rec.ro = new ResizeObserver(function () {
          if (measuring) return;
          var w = el.getBoundingClientRect().width;
          if (!w || Math.abs(w - rec.w) < 1) return;
          rec.w = w;
          el.style.minHeight = "";
          var sn = rec.save ? rec.save() : null;
          var m = measureAll(el, rec.n, rec.render);
          if (m > 0) el.style.minHeight = m + "px";
          if (rec.restore) rec.restore(sn);
          rec.w = el.getBoundingClientRect().width;
        });
        rec.ro.observe(el);
      }
      return max;
    },

    hold: function (el) {
      if (!el) return;
      var h = natural(el);
      var cur = parseFloat(el.style.minHeight) || 0;
      if (h > cur) el.style.minHeight = h + "px";
    },

    /* Drop every reservation and take them again. */
    remeasure: function () {
      primed.forEach(function (p) {
        var sn = p.save ? p.save() : null;
        p.el.style.minHeight = "";
        p.el.style.minHeight = measureAll(p.el, p.n, p.render) + "px";
        if (p.restore) p.restore(sn);
      });
    },

    /* Containers held by latch cannot be re-measured without knowing their
       states, so on resize they are released and allowed to re-latch. */
    release: function (el) { if (el) el.style.minHeight = ""; }
  };

  var t;
  window.addEventListener("resize", function () {
    clearTimeout(t);
    t = setTimeout(function () { Steady.remeasure(); }, 150);
  });
  if (document.fonts && document.fonts.ready) {
    document.fonts.ready.then(function () { Steady.remeasure(); });
  }

  window.Steady = Steady;
})();

</script>

(function () {
  "use strict";
  function esc(s) { return String(s).replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;"); }
  function icon(n) { return '<svg class="i"><use href="#i-' + n + '"/></svg>'; }
  function ws(s) { return esc(s).replace(/ /g, '<span class="tok__ws">·</span>'); }
  /* .demo__foot lays its children out as a flex row, so note text has to arrive
     as one element - otherwise every <strong> starts its own column. */
  function setNote(el, name, html) { el.innerHTML = icon(name) + "<span>" + html + "</span>"; }

  /* -- L1 . Token Roulette --------------------------------------------------
     A real (very small) next-word model built from the course's own prose by
     build/corpus.py. Trigram where it offers a genuine choice, bigram otherwise,
     so the chain runs as long as the learner keeps clicking. Temperature is
     p^(1/T) renormalised - the same maths a real sampler uses. */
  (function () {
    if (!document.getElementById("roulette")) return;
    var START = "\u0002", END = "\u0003", SEP = "\u0001";
    var elS = document.getElementById("rSentence"), elT = document.getElementById("rTokens"),
        elN = document.getElementById("rNote"), elR = document.getElementById("rRolls"),
        elO = document.getElementById("rOrder"),
        temp = document.getElementById("temp"), tempOut = document.getElementById("rTemp");
    var hist, built, done, T = 0.8, order = "", greedy = 0;
    /* Real generators take a min_length parameter so a sample cannot stop after
       four words. Same idea: end-of-sentence is held back until the sentence has
       something to it, and the panel says so rather than hiding it. */
    var MINLEN = 8;
    /* Every table is capped at this many candidates, so the list has a known
       tallest state to reserve room for. */
    var MAXROWS = 8;

    /* Two things above the buttons can change height between steps: the
       candidate list (fewer candidates = shorter row count, and none at all
       once the walk ends) and the caption above the slider (which wraps to a
       different number of lines depending on which table is in play). Both are
       held at their tallest so "Let it pick" never moves out from under the
       pointer.

       pad() fills the candidate list out to MAXROWS with invisible rows.

       primeOrder() hands the caption to Steady, which measures the longest
       string it can produce and reserves that height. Steady re-measures when
       the element's width actually changes and once the real typeface loads,
       which is what makes an up-front measurement safe here: at load the panel
       sits inside the gated region at the wrong width, and the fallback font
       wraps a line short of the real one. */
    function pad(el, from) {
      for (var g = from; g < MAXROWS; g++) {
        var ghost = document.createElement("span");
        ghost.className = "token token--ghost";
        ghost.setAttribute("aria-hidden", "true");
        ghost.innerHTML = '<span class="token__word">&nbsp;</span>' +
          '<span class="token__meter"></span><span class="token__pct">&nbsp;</span>';
        el.appendChild(ghost);
      }
    }
    var WORST = 'Looking at overall word frequency - nothing recorded follows ' +
      'that word - <strong>8</strong> candidates, ranked by how often each ' +
      'one followed in the training text. <span class="muted">End-of-sentence is ' +
      'held back until ' + MINLEN + ' words - the same <em>min length</em> ' +
      'setting real generators use.</span>';
    /* The caption's longest possible state, primed once by Steady rather than
       re-measured on every render. WORST is a real string it can produce. */
    function primeOrder() {
      Steady.prime(elO, 1, function () { elO.innerHTML = WORST; });
    }

    function reset() { hist = [START, START]; built = []; done = false; greedy = 0; elR.innerHTML = ""; }

    /* Drop end-of-sentence until MINLEN words are down. If that leaves nothing --
       the corpus is small, so a word's only recorded continuation is sometimes
       the end -- back off one more level to overall word frequency rather than
       killing the walk. Trigram, then bigram, then unigram. */
    function allowed(list, n) {
      if (n >= MINLEN) return list;
      var f = list.filter(function (o) { return o[0] !== END; });
      if (f.length) return f;
      order = "overall word frequency - nothing recorded follows that word";
      return RMODEL.uni;
    }

    function raw(h) {
      var k = h[h.length - 2] + SEP + h[h.length - 1];
      if (RMODEL.tri[k]) { order = "the last two words"; return RMODEL.tri[k]; }
      var b = RMODEL.bi[h[h.length - 1]];
      if (b) { order = "the last word only"; return b; }
      order = ""; return null;
    }
    function temper(list) {
      var tot = list.reduce(function (a, o) { return a + o[1]; }, 0);
      var w = list.map(function (o) { return Math.pow(o[1] / tot, 1 / T); });
      var s = w.reduce(function (a, b) { return a + b; }, 0);
      return list.map(function (o, i) { return [o[0], (w[i] / s) * 100]; });
    }
    function sample(list) {
      var r = Math.random() * 100, acc = 0;
      for (var i = 0; i < list.length; i++) { acc += list[i][1]; if (r <= acc) return list[i][0]; }
      return list[list.length - 1][0];
    }
    function completeFrom(h) {
      var loc = h.slice(), out = [], n = built.length;
      for (var i = 0; i < 30; i++) {
        var o = raw(loc); if (!o) break;
        var pick = sample(temper(allowed(o, n + out.length)));
        if (pick === END) break;
        out.push(pick); loc.push(pick);
      }
      return out;
    }
    function step() {
      var o = raw(hist); if (!o) { done = true; return; }
      var pick = sample(temper(allowed(o, built.length)));
      if (pick === END) { done = true; return; }
      built.push(pick); hist.push(pick);
    }

    function render() {
      elS.innerHTML = (built.length ? esc(built.join(" ")) : '<span class="muted">the sentence starts here</span>') +
                      (done ? "" : ' <span class="cursor"></span>');
      elT.innerHTML = "";
      elT.className = "tokens";
      elT.style.minHeight = "";

        pad(elT, 0);

          built.length + " word" + (built.length === 1 ? "" : "s") +

        elT.style.minHeight = tall + "px";
        elO.textContent = "";
        setNote(elN, "history", "Run it again. The sentence comes out different every time and nothing about the " +
          "model has changed - only the roll. Move the temperature first and the difference gets larger.");
        return;
      }
      var o = allowed(raw(hist), built.length);
      if (!o) { done = true; render(); return; }
      elO.innerHTML = "Looking at " + order + " - <strong>" + o.length +
        "</strong> candidate" + (o.length === 1 ? "" : "s") +
        ", ranked by how often each one followed in the training text." +
        (built.length < MINLEN
          ? ' <span class="muted">End-of-sentence is held back until ' + MINLEN +
            " words - the same <em>min length</em> setting real generators use.</span>"
          : "");
      var ranked = temper(o);
      ranked.forEach(function (t, ix) {
        var b = document.createElement("button");
        b.className = "token"; b.type = "button";
        var label = t[0] === END ? '<em class="muted">end of sentence</em>' : ws(t[0]);
        b.innerHTML = '<span class="token__word">' + label + "</span>" +
          '<span class="token__meter"><i style="width:' + t[1].toFixed(1) + '%"></i></span>' +
          '<span class="token__pct">' + t[1].toFixed(0) + "%</span>";
        b.addEventListener("click", function () {
          elR.innerHTML = "";
          greedy = ix === 0 ? greedy + 1 : 0;
          if (t[0] === END) { done = true; } else { built.push(t[0]); hist.push(t[0]); }
          render();
        });
        elT.appendChild(b);
      });
      pad(elT, ranked.length);
      if (greedy >= 4) {
        setNote(elN, "lightbulb", "You have taken the top option " + greedy + " times running. That is " +
          "<strong>greedy decoding</strong> - always the leader, never a gamble - and it is a real " +
          "strategy with a real cost: it is repetitive, and it is what a temperature near zero gives you. " +
          "Take a lower-ranked word and see where the sentence goes instead.");
      } else {
        setNote(elN, "arrow-right", built.length === 0
          ? "Pick a word to begin, or let it pick for you. Keep going as long as you like - there is no fixed number of steps."
          : "Keep going. Move the temperature slider and watch the same candidates redistribute - the words never change, only how strongly the leader is favored.");
      }
    }

    ["input", "pointerdown", "keydown"].forEach(function (e) {
      temp.addEventListener(e, function () {
        T = parseInt(temp.value, 10) / 100;
        tempOut.textContent = "Temperature " + T.toFixed(2);
        render();
      });
    });
    document.getElementById("rStep").addEventListener("click", function () { elR.innerHTML = ""; step(); render(); });
    document.getElementById("rFinish").addEventListener("click", function () {
      elR.innerHTML = "";
      var guard = 0;
      while (!done && guard++ < 40) step();
      done = true; render();
    });
    document.getElementById("rFive").addEventListener("click", function () {
      var outs = [], seen = {};
      for (var i = 0; i < 5; i++) outs.push(built.concat(completeFrom(hist)).join(" "));
      outs.forEach(function (s) { seen[s] = 1; });
      elR.innerHTML = outs.map(function (s, i) {
        return '<div class="roll"><span class="roll__n">' + (i + 1) +
               '</span><span class="roll__t">' + esc(s) + "</span></div>";
      }).join("");
      var distinct = Object.keys(seen).length;
      setNote(elN, "lightbulb", "Five continuations from exactly the same starting point, at temperature " +
        T.toFixed(2) + " - <strong>" + distinct + " of them different</strong>. " +

/* Inline vocabulary. A term in the prose is written as
     <b class="vt" data-v="token"><i>token</i></b>
   and this turns it into a button that opens its own definition in place.
   The data is inlined by pack.py (build/generated/vocab_data.js) - nothing is
   fetched, so this works from file://, from an LMS page, and offline. */
(function () {
  "use strict";
  if (typeof VOCAB === "undefined" || window.__vocabReady) return;
  window.__vocabReady = true;

  var open = null;

  function close() {
    if (!open) return;
    open.btn.setAttribute("aria-expanded", "false");
    if (open.pop.parentNode) open.pop.parentNode.removeChild(open.pop);
    open = null;
  }

  function build(rec, btn) {
    var pop = document.createElement("span");
    pop.className = "vpop";
    pop.setAttribute("role", "dialog");
    pop.setAttribute("aria-label", rec.t);
    var eg = rec.e && rec.e.length
      ? '<span class="vpop__eg">' + rec.e[0] + "</span>" : "";
    pop.innerHTML =
      '<span class="vpop__top"><b class="vpop__name">' + rec.t + "</b>" +
      '<span class="vpop__from">Lesson ' + (rec.l < 10 ? "0" : "") + rec.l + "</span></span>" +
      '<span class="vpop__def">' + rec.d + "</span>" +
      '<span class="vpop__why">' + rec.w + "</span>" + eg +
      /* New tab, always. Inside an LMS frame this link would otherwise
         navigate the frame away from the lesson, and coming back re-loads the
         page - which throws away the prediction the learner committed to and
         everything they have done since. A vocabulary lookup is a side trip,
         not a destination. rel=noopener because target=_blank without it hands
         the new tab a reference back to this window. */
      '<span class="vpop__foot"><a class="vpop__more" target="_blank" ' +
      'rel="noopener" href="../vocabulary.html#' +
      rec.s + '">Full entry, with examples <svg class="i"><use href="#i-arrow-right"/></svg>' +
      '<span class="visually-hidden">(opens in a new tab)</span></a>' +
      '<button class="vpop__x" type="button" aria-label="Close">' +
      '<svg class="i"><use href="#i-x"/></svg></button></span>';

    pop.addEventListener("click", function (e) {
      if (e.target.closest(".vpop__x")) { close(); btn.focus(); }
      e.stopPropagation();
    });
    return pop;
  }

  /* Keep the panel inside the page. It is positioned relative to the term, so
     the only thing that can go wrong is running off the right edge on a narrow
     screen; nudge it back rather than letting the page scroll sideways. */
  function place(pop, btn) {
    pop.style.left = "0px";
    var r = pop.getBoundingClientRect();
    var over = r.right - (document.documentElement.clientWidth - 12);
    if (over > 0) pop.style.left = -Math.min(over, r.left - 12) + "px";
  }

  document.addEventListener("click", function (e) {
    var btn = e.target.closest(".vt");
    if (!btn) { close(); return; }
    var key = btn.getAttribute("data-v"), rec = VOCAB[key];
    if (!rec) return;                       /* unknown key: leave it as text */
    var wasOpen = open && open.btn === btn;
    close();
    if (wasOpen) return;
    var pop = build(rec, btn);
    btn.appendChild(pop);
    btn.setAttribute("aria-expanded", "true");
    open = { btn: btn, pop: pop };
    place(pop, btn);
  });

  document.addEventListener("keydown", function (e) {
    if (e.key === "Escape" && open) { var b = open.btn; close(); b.focus(); }
  });

  /* Every .vt becomes focusable and announces itself, without the authoring
     markup having to carry any of that. */
  function arm() {
    var all = document.querySelectorAll(".vt");
    for (var i = 0; i < all.length; i++) {
      var b = all[i];
      if (b.hasAttribute("data-armed")) continue;
      b.setAttribute("data-armed", "1");
      b.setAttribute("role", "button");
      b.setAttribute("tabindex", "0");
      b.setAttribute("aria-expanded", "false");
      var rec = VOCAB[b.getAttribute("data-v")];
      if (rec) b.setAttribute("aria-label", rec.t + " - definition");
      b.addEventListener("keydown", function (e) {
        if (e.key === "Enter" || e.key === " ") { e.preventDefault(); this.click(); }
      });
    }
  }
  if (document.readyState === "loading")
    document.addEventListener("DOMContentLoaded", arm);
  else arm();
  window.armVocab = arm;      /* gated content reveals more terms later */
})();

</script>
